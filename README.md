# kineskop-app.github.io

Static site of the Kineskop studio (no build step): `/` studio page, `/sweatercat/` the app (en, `uk/`), `/lastrun/` the game Last Run (en, `uk/`), each with privacy and support pages.
Landings are generated by `tools/build_site.py` (Sweater Cat) and `tools/build_lastrun.py` (Last Run, own look in `lastrun/lastrun.css`).
 Publish: GitHub account **kineskop-app**, public repo
**kineskop-app.github.io**, and push the contents of this folder to its `main` branch — GitHub Pages serves it at
https://kineskop-app.github.io/ (Settings → Pages → Deploy from branch → main / root).

Before publishing replace:

App Store Connect URLs: Privacy — https://kineskop-app.github.io/sweatercat/privacy.html, Support — https://kineskop-app.github.io/sweatercat/support.html
Last Run (App Store + Google Play): Privacy — https://kineskop-app.github.io/lastrun/privacy.html, Support — https://kineskop-app.github.io/lastrun/support.html

Notify-me form posts to FormSubmit (https://formsubmit.co) → kineskop.app@gmail.com; the very first submission sends an
activation email that has to be confirmed once.
