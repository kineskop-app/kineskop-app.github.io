Quick answers

  • Restore the full game on a new phone: open chapter two — on the unlock screen tap Restore (same Apple ID or Google account).
  • Text too small or too big: main menu → Settings → Text size.
  • Change the language: the game follows your phone's language. On iPhone you can also pick it in iPhone Settings → Last Run → Language.
  • Play another way: there are 3 save slots, and after any chapter you can replay it from the flowchart.
  • Lost progress after reinstalling: progress is stored only on the device, so deleting the game deletes it. Purchases can always be restored.

Швидкі відповіді

  • Відновити повну гру на новому телефоні: відкрий розділ 2 — на екрані покупки натисни «Відновити» (той самий Apple ID чи акаунт Google).
  • Текст замалий чи завеликий: головне меню → Налаштування → Розмір тексту.
  • Змінити мову: гра говорить мовою телефона. На iPhone мову можна обрати й окремо: Параметри iPhone → Last Run → Мова.
  • Пройти інакше: є 3 слоти для проходжень, а після будь-якого розділу його можна переграти з блок-схеми.
  • Зник прогрес після перевстановлення: прогрес зберігається лише на пристрої, тож видалення гри видаляє і його. Покупку завжди можна відновити.
